# Trading OS

Premium desktop trading terminal — private beta landing site.

## Quick start

```bash
cd trading-os
npm install
npm run dev
```

Open [http://localhost:5002](http://localhost:5002).

## Deploy

This folder is a standalone Next.js app intended for its own Vercel project (`trading-os`), separate from AXE Companion.

Target GitHub repository: [TRADING-AXE-OS-APPS/TRADING-OS-](https://github.com/TRADING-AXE-OS-APPS/TRADING-OS-)
