# Order blocks (AXE core)

## Definition
- Last **opposing** candle before a strong impulse: **bullish OB** = demand before up-move; **bearish OB** = supply before down-move.

## Entry discipline
- **Mitigation / retrace** into the OB body (often 50–62% of the block) with confirmation close improves R:R versus chasing the impulse.

## Invalidation
- A decisive close **through** the OB in the wrong direction for your thesis invalidates that block as active support/resistance for the current narrative.

## Confluence
- Stack OB logic with liquidity sweep + FVG + session bias — not isolated single-candle zones in a vacuum.
