# Mistake tags (AXE)

## Purpose
- Normalize **failure modes** so AXE and the trader see patterns: late entry, moved stop, oversized, traded through news, ignored HTF bias, etc.

## Examples
- `late_entry` `early_exit` `oversized` `no_plan` `revenge` `news_ignore` `low_conviction` `chased` `stopped_precisely` `target_greed`

## Usage
- Map broker/journal labels to tags for analytics. Prefer **one primary** mistake per trade to keep signal clean.

## Tags
- review:mistakes journal:taxonomy
