4 · Open questions before I start coding

Where does Supply / Demand get its anchors?
  • Option A — derived from PDH / PDL (top 25% of yesterday's range = supply, bottom 25% = demand). Same data Day-fib uses today; just rendered as a separate indicator.
  • Option B — derived from the most recent swing High / Low on the active TF. Updates intraday as structure forms; not tied to PDH/PDL.
  • Option C — both, with a sub-toggle "Daily / Swing" inside the indicator panel.
"Extend left" button on fib
  • Adds a second toggle next to the existing right-extend setting. When on, fib lines run from the chart's left edge through the anchor and out to the right rail. When off, only the segment between anchors + right extension renders. Per-fib annotation (not global), persisted in the annotation's settings.
Volumetric Order Blocks — am I rendering them?
  • Yes — already shipped. Inside each OB you should see a horizontal split (green buyer % bottom, red seller % top), plus a right-rail label like 1.08K (13%) stacked above B 62%. If you don't see those numbers, the candle feed isn't returning tickVolume on this account / TF, or the OB is shorter than 12 px (label hidden to avoid clutter on tiny zones).
iFVG extension width
  • Today FVG goes a fixed ~4 bars right; OB extends to the projection cursor. Plan: make iFVG behave identical to OB — extends to the projection cursor when on, or 5 bars by default — and add the same per-side count selector (1, 2, 3) you have for OB. FVG stays at 2 bars (you said it's fine).
