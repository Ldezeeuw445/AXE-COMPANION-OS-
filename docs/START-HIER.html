Jouw vijf stappen
1

De branch naar de VPS brengen

15 min

Alles wat gerepareerd is staat op de branch, niet op je server. De draaiende code is van 23 augustus.

cd /root/AXE-COMPANION-OS-
git fetch origin
git checkout deployed
git reset --hard origin/claude/axe-companion-audit-launch-nz58dg
npm ci && npm run build
systemctl restart axe-companion
curl -s -o /dev/null -w "%{http_code}\n" https://www.axecompanion.com/robots.txt

Die laatste regel is je bewijs: 200 = geland, 404 = de build mislukte stil en het oude proces serveert nog. Loopt de build vast op geheugen: systemctl stop axe-browser-agent, bouwen, weer starten.

→ Brengt live: twee MT5-bugfixes, de MT5 Doctor, de lege-env-fallback, robots.txt, en het verwijderen van /migrations en /shadcn-demo

2

Unusual Whales naar Supabase Edge secrets

5 min

Je token staat in .env.local op de VPS, waar intel-proxy er niet bij kan. Edge functions lezen alleen Supabase-secrets.

Test eerst of de token die je hebt nog leeft:

UW=$(grep '^UNUSUAL_WHALES_TOKEN=' /root/AXE-COMPANION-OS-/.env.local | cut -d= -f2- | tr -d '\042\047' | xargs)
curl -s -o /dev/null -w "HTTP %{http_code}\n" -H "Authorization: Bearer $UW" \
  https://api.unusualwhales.com/api/market/market-tide

200 → kopieer die waarde naar Supabase → Edge Functions → Secrets als UNUSUAL_WHALES_TOKEN. 401 → nieuwe halen op unusualwhales.com.

→ Zet weer aan: insider trades, congress trades, dark pool, unusual options, market tide

3

intel-proxy opnieuw deployen

2 min

De gedeployde functie kent zeven acties helemaal niet — ze geven unknown_action. De repo heeft ze wel. De CI-workflow "slaagde" negen keer in twaalf seconden; dat was de overslaan-tak omdat een secret ontbrak.

supabase functions deploy intel-proxy --project-ref pqnngpcgbdwxavbatbia

Of duurzamer: zet SUPABASE_ACCESS_TOKEN als GitHub-secret, dan deployt de workflow voortaan vanzelf.

→ Zet weer aan: vessels, conflicten, energie, cyber, chokepoints, radar, noodmonitor

4

Eén MT5-account opnieuw koppelen

5 min

Je drie MT5-rijen wijzen naar accounts van je oude token — geen ervan bestaat nog. Ze kunnen niet synchroniseren, wat de status ook zegt.

Koppel er één van je vijf huidige accounts (MT5 100K DEMO, 50K, 5K, OANDA DEMO 50K) via de app. Daarna vult mt5-sync zichzelf.

5

Eén keer ingelogd doorlopen

30 min

Het enige wat ik principieel niet voor je kan doen, en het enige wat "launch ready" echt bewijst.

Watchlist-symbool toevoegen · alert aanmaken en laten afgaan · Alpaca paper-order plaatsen · Cockpit openen als Pro · push ontvangen op je telefoon · één echte Stripe-checkout van begin tot eind.

Watchlists, alerts, posities, vault en journal staan alle vijf op nul rijen. Eén doorloop maakt duidelijk of de schrijfpaden werken of dat niemand ooit zo ver kwam.
